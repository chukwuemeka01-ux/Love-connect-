LOVE CONNECT — PWA starter demo

WHAT THIS IS
A starter package that can become an installable web app (PWA) after it is hosted on an HTTPS website.
It is still a demo: no real accounts, real users, server, or live chat.

FILES
- index.html: the prototype
- manifest.json: app name, colours, and install settings
- sw.js: basic offline caching
- icon.svg: app icon

IMPORTANT
Opening index.html directly from your phone's Downloads folder will NOT enable PWA installation.
The files must be uploaded together to a public HTTPS host first. After that, open the hosted site in Chrome on Android and use Chrome's menu > Install app or Add to Home screen (wording varies).

This package does not create an APK. A native Android APK requires an additional build step.
For a real dating service, use proper age controls (18+), privacy/security practices, moderation, and a secure backend before publishing.
